# KAMP-paper

Code for "KAMP" (Kernel/K-function Adjusted via Marked Permutation) — simulations and real-data
analysis of Ripley's K-based spatial clustering statistics for multiplex imaging data, using the
HGSOC (ovarian cancer) VectraPolaris dataset.

## Repository structure

- `source/` — core functions (simulating point patterns, computing K/KAMP statistics, permutation
  distributions) and the scripts that run each simulation study
- `source/simulations/` — one `.R`/`.sh` pair per simulation study; the `.sh` files submit the `.R`
  script as a SLURM array job, one task per parameter scenario
- `analysis/` — R Markdown files that load simulation/real-data output and produce the paper's figures
- `data/` — processed real-data objects (gitignored; regenerated by `source/vectraPolarisdata*.R`)
- `output/` — simulation results and rendered figures (gitignored; regenerated by the scripts/Rmds below)
- `sandbox/` — exploratory scripts and archived submission materials (gitignored, not part of the
  reproducible pipeline)

## Workflow

Each simulation script writes its results to a date-stamped subfolder under `output/`
(`output/<study>/<YYYYMMDD>/...`). The corresponding analysis `.Rmd` points at a specific date folder
via `list.files()` — if you re-run a simulation, update that path in the `.Rmd` to the new date before
re-knitting.

| Script | Produces |

| `source/vectraPolarisdata.R` | `data/processed_ovarian_data.Rda`; per-sample univariate K/KAMP results in `output/VPdata/` |
| `source/vectraPolarisdata_biv.R` | `data/processed_ovarian_data.Rda` (with B cell/macrophage phenotype labels); per-sample bivariate results in `output/VPdata_bivariate/` |

### 3. Render the analysis `.Rmd` files to produce figures

Knit each file in `analysis/`; figures are saved as `.png` files under `output/`.
